# Required LaTeX Document Template

Use this EXACT preamble and macro structure:

% ===== Document Preamble =====
\documentclass[11pt]{article}
\usepackage[margin=0.5in]{geometry}
\usepackage{amsmath,amssymb}
\usepackage{xcolor}
\usepackage{enumitem}
\usepackage{needspace}
\usepackage{comment}

% ===== Colors =====
\definecolor{AnsRed}{RGB}{170,0,0}
\definecolor{WrongBlue}{RGB}{0,0,160}
\definecolor{SkipGray}{RGB}{120,120,120}

% ===== Choice list styling (tight, consistent) =====
\setlist[enumerate]{%
  leftmargin=1.5em,
  itemsep=0.25em,
  topsep=0.25em,
  label=\textbf{\Alph*.}
}

% ===== Style Wrappers =====
\newcommand{\QuestionStyle}[1]{{\large\bfseries\boldmath #1}}
\newcommand{\AnswerStyle}[1]{{\large\bfseries\boldmath #1}}
\newcommand{\ReasonStyle}[1]{{\normalsize #1}}

% ===== Show / Hide Reasoning Toggle =====
\newif\ifshowreason
\showreasontrue      % Instructor version
% \showreasonfalse   % Student version

% ===== Choice Item Macros (Answer + Reasoning) =====
% Usage:
%   \Correct{Answer}{Reasoning}
%   \Wrong{Answer}{Reasoning}

\newcommand{\Correct}[2]{%
  \item \AnswerStyle{\textcolor{AnsRed}{#1}}%
  \ifshowreason\\[-0.2em]
    \ReasonStyle{\textcolor{AnsRed}{#2}}%
  \fi
}

\newcommand{\Wrong}[2]{%
  \item \AnswerStyle{\textcolor{WrongBlue}{#1}}%
  \ifshowreason\\[-0.2em]
    \ReasonStyle{\textcolor{WrongBlue}{#2}}%
  \fi
}

% ===== Multiple-Choice Question Block Macro =====
% Usage: \QBlock{Q1}{stem...}{<items>}{answer key}

\newcommand{\QBlock}[4]{%
  \Needspace{8\baselineskip}%
  \noindent
  \begin{minipage}{\linewidth}
    \QuestionStyle{#1.~#2}

    \vspace{0.25em}
    \begin{enumerate}
      #3
    \end{enumerate}

    \vspace{0.1em}
    \noindent\textcolor{AnsRed}{\textit{\textbf{Answer:}~#4}}

    \vspace{0.25em}
    \hrule height 0.4pt
  \end{minipage}
  \vspace{0.75em}
}

% ===== Open-Ended Question Block Macro =====
% Usage: \OEBlock{Q1}{stem...}{answer text}

\newcommand{\OEBlock}[3]{%
  \Needspace{5\baselineskip}%
  \noindent
  \begin{minipage}{\linewidth}
    \QuestionStyle{#1.~#2}

    \vspace{0.25em}
    \noindent\textcolor{AnsRed}{\textit{\textbf{Answer:}~#3}}

    \vspace{0.25em}
    \hrule height 0.4pt
  \end{minipage}
  \vspace{0.75em}
}

% ===== Multi-Part Question Block Macro =====
% Usage: \MPBlock{Q1}{stem...}{<parts>}

\newcommand{\MPBlock}[3]{%
  \Needspace{8\baselineskip}%
  \noindent
  \begin{minipage}{\linewidth}
    \QuestionStyle{#1.~#2}

    \vspace{0.25em}
    #3

    \vspace{0.25em}
    \hrule height 0.4pt
  \end{minipage}
  \vspace{0.75em}
}

% ===== MC Sub-Part Macro =====
% Usage: \MCPart{a}{stem...}{<items>}{answer key}

\newcommand{\MCPart}[4]{%
  \par\vspace{0.35em}
  \noindent\textbf{(#1)}~#2
  \begin{enumerate}
    #3
  \end{enumerate}
  \vspace{0.1em}
  \noindent\textit{\textbf{Answer:}~#4}
  \par
}

% ===== Open-Ended Sub-Part Macro =====
% Usage: \OEPart{a}{stem...}{answer text}

\newcommand{\OEPart}[3]{%
  \par\vspace{0.35em}
  \noindent\textbf{(#1)}~#2
  \par\vspace{0.15em}
  \noindent\textit{\textbf{Answer:}~#3}
  \par
}

% ===== Skipped Question Note Macro =====
% Usage: \SkipBlock{Q1}{reason}

\newcommand{\SkipBlock}[2]{%
  \noindent\textcolor{SkipGray}{\textit{[#1 omitted: #2]}}%
  \vspace{0.5em}\par
}


# Document Structure

After the preamble, structure your document as:

```latex
% ===== Document Start =====

\begin{document}

\begin{center}
{\huge \textbf{<TITLE>}}\\[0.25em]
{\Large <SUBTITLE>}\\[0.25em]
% Only include the next line when requirements.show_answers is true (omit it entirely when false):
{\large Answer the questions below. Correct answers are in \textcolor{AnsRed}{RED}, while incorrect answers are in \textcolor{WrongBlue}{BLUE}.}
\end{center}

\vspace{0.75em}

% Questions go here

\end{document}
```

Header field rules — apply in order:

**`<TITLE>`** (the big heading — what TYPE of document this is):
1. Use `document.title` if it is explicitly set by the user (non-empty).
2. Otherwise, if `document.theme` is non-empty, produce: "[Theme] Practice Questions"
   (e.g. "Physics Practice Questions" for theme "physics_abstract").
3. Otherwise default to: "Isomorphic Practice Questions".
Do NOT use `document.source_title` as the `<TITLE>` — the source title belongs in `<SUBTITLE>`.

**`<SUBTITLE>`** (the source context line — where questions came from):
1. Use `document.subtitle` if non-empty.
2. Otherwise build from available fields in priority order:
   - If `document.course` is non-empty: use it (e.g. "PHYS 1101").
   - If `document.source_title` is non-empty: use it (e.g. "Quiz #2").
   - If `document.theme` is non-empty: use theme as a fallback.
3. If nothing is available: omit the subtitle line entirely.

**Color-coding instruction line** (third line):
- Include it only when `requirements.show_answers` is `true` (the default).
- Omit it entirely when `requirements.show_answers` is `false`.
- When omitted, also set `\showreasonfalse` instead of `\showreasontrue` in the preamble
  so that explanations are hidden throughout the document.

# Formatting Rules

Number all output questions sequentially (Q1, Q2, Q3, ...) regardless of source_id.

Apply the following rules in order for each question:

**Rule 1 - Skipped questions** (`skipped=true`):
- Use `\SkipBlock{Q<number>}{<skip_reason>}`
- Do NOT use any other macro; skip immediately to the next question.

**Rule 2 - Question type determines the macro:**

*Multiple-choice* (`question_type="multiple_choice"`):
- Use `\QBlock{Q<number>}{<stem>}{<options>}{<answer key>}`
- `<options>`: each choice uses `\Correct{<text>}{<explanation>}` or `\Wrong{<text>}{<explanation>}`
- `<answer key>`: the letter (e.g., `B`) of the correct option

*Open-ended* (`question_type="open_ended"`):
- Use `\OEBlock{Q<number>}{<stem>}{<answer>}`
- `<answer>`: the solution text from the `answer` field

*Multi-part* (`question_type="multi_part"`):
- Use `\MPBlock{Q<number>}{<stem>}{<parts>}`
- `<stem>`: the shared context text
- `<parts>`: a sequence of `\MCPart` and/or `\OEPart` calls for each entry in `parts[]`:
  - MC sub-part: `\MCPart{<label>}{<stem>}{<options>}{<answer key>}`
  - OE sub-part: `\OEPart{<label>}{<stem>}{<answer>}`

**Point values** — when `questions[i].points > 0`, append the point value to the stem:
- Format: `<stem text>\hfill\textit{(\,X\,pts)}`  where X is the numeric value.
- Use integer display when the value is a whole number (e.g. 5.0 → "5 pts").
- Example stem arg: `A ball is dropped from rest.\hfill\textit{(\,5\,pts)}`

**General rules:**
- All math formatted as LaTeX math (`$...$` for inline, `\[...\]` for display).
- Preserve all mathematical notation exactly.
- Correct MC answers appear in RED (AnsRed color); incorrect in BLUE (WrongBlue color).
- When `requirements.show_answers` is `false`, use plain text for all options (no color
  macros). Replace `\Correct{text}{explanation}` with `\item text` and `\Wrong{text}{explanation}`
  with `\item text` — no colors, no explanations, no answer keys in `\QBlock`.
