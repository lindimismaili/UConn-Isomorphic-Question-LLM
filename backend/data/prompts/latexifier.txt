# Document Structure

After the preamble, structure your document as:

```latex
% ===== Document Start =====

\begin{document}

\begin{center}
{\huge \textbf{<TITLE>}}\\[0.25em]
{\Large <SUBTITLE>}\\[0.25em]
% Only include the next line for instructor versions with answers shown; omit it entirely for student versions:
{\large <COLOR LEGEND>}
\end{center}

\vspace{0.75em}

% Questions go here

\end{document}
```

Header rules — apply in order:

The document theme may arrive as a `Label: guidance` string (a user-selected
theme label followed by generation guidance). Wherever the header rules below
use the theme, use ONLY the text before the first colon (the label) — never
the guidance text after it.

**`<TITLE>`** (the big heading — what TYPE of document this is):
1. Use the title explicitly requested by the user when one exists.
2. Otherwise, if a document theme is available, produce: "[Theme label] Practice Questions"
   (e.g. theme "Video Games: re-cast each scenario..." → "Video Games Practice Questions").
3. Otherwise default to: "Isomorphic Practice Questions".
Do NOT use the source title as the main title; the source title belongs in the subtitle.

**`<SUBTITLE>`** (the source context line — where questions came from):
1. Use the document subtitle when one is available.
2. Otherwise build from available metadata in priority order:
   - Course code or course name, if available (e.g. "PHYS 1101").
   - Source title, if available (e.g. "Quiz #2").
   - Theme label as a fallback, if available.
3. If nothing is available: omit the subtitle line entirely.
Keep the subtitle about the SOURCE CONTEXT, never about the question format
(do not write "Multiple choice questions" or similar as the subtitle).

**`<COLOR LEGEND>`** (third line) — choose it by the question types present in the document:
- Only multiple-choice questions:
  `Answer the questions below. Correct answers are in \textcolor{AnsRed}{RED}, while incorrect answers are in \textcolor{WrongBlue}{BLUE}.`
- Only open-ended and/or multi-part questions:
  `Answer the questions below. Answers are in \textcolor{AnsRed}{RED}, with explanations in \textcolor{WrongBlue}{BLUE}.`
- A mix of both:
  `Answer the questions below. Correct answers are in \textcolor{AnsRed}{RED}, incorrect answers are in \textcolor{WrongBlue}{BLUE}, and explanations for open-ended questions are in \textcolor{WrongBlue}{BLUE}.`
- Include the legend only for instructor versions with answers shown.
- Omit it entirely for student versions with answers hidden.
- When omitted, also set `\showreasonfalse` instead of `\showreasontrue` in the preamble
  so that explanations are hidden throughout the document.

# Formatting Rules

Number all rendered questions sequentially (Q1, Q2, Q3, ...) regardless of their source identifiers.

**Shared-context groups** — some questions carry a non-empty `group_id` with shared
`group_context`. Render the shared context with `\GroupPreamble{<group_context>}`
ONCE, immediately before the first question whose `group_id` differs from the previous
question's. Every member of the group then renders with its normal question macro
below the preamble; never repeat the preamble per member. If the shared context names
a question range, phrase it from the RENDERED sequential numbers (e.g. a group spanning
the 3rd through 7th rendered questions reads "For questions 3-7, consider ..."), not the
source numbers. Questions with empty `group_id` get no preamble.

Apply the following rules in order for each question:

**Rule 1 - Skipped questions**:
- Use `\SkipBlock{Q<number>}{<skip reason>}`
- Do NOT use any other macro; skip immediately to the next question.

**Rule 2 - Question type determines the macro:**

*Multiple-choice*:
- Use `\QBlock{Q<number>}{<stem>}{<options>}{<answer key>}`
- `<options>`: each choice uses `\Correct{<text>}{<explanation>}` or `\Wrong{<text>}{<explanation>}`
- `<answer key>`: the letter (e.g., `B`) of the correct option

*Open-ended*:
- Use `\OEBlock{Q<number>}{<stem>}{<answer>}{<explanation>}`
- `<answer>`: the concise final result for that question
- `<explanation>`: the supporting reasoning/derivation from the question's `explanation`
  field (LaTeX equations preserved); pass an empty group `{}` if no explanation exists

*Multi-part*:
- Use `\MPBlock{Q<number>}{<stem>}{<parts>}`
- `<stem>`: the shared context text
- `<parts>`: a sequence of `\MCPart` and/or `\OEPart` calls for each sub-part:
  - MC sub-part: `\MCPart{<label>}{<stem>}{<options>}{<answer key>}`
  - OE sub-part: `\OEPart{<label>}{<stem>}{<answer>}{<explanation>}` — same answer/explanation
    split as `\OEBlock`, using the part's `explanation` field

**Point values** — when a question has a positive point value, append the point value to the stem:
- Format: `<stem text>\hfill\textit{(\,X\,pts)}`  where X is the numeric value.
- Use integer display when the value is a whole number (e.g. 5.0 → "5 pts").
- Example stem arg: `A ball is dropped from rest.\hfill\textit{(\,5\,pts)}`

**General rules:**
- All math formatted as LaTeX math (`$...$` for inline, `\[...\]` for display).
- Preserve all mathematical notation exactly.
- Correct MC answers appear in RED (AnsRed color); incorrect in BLUE (WrongBlue color).
- Open-ended answers appear in RED; their explanations in BLUE.
- For student versions with answers hidden, use plain text for all options (no color
  macros). Replace `\Correct{text}{explanation}` with `\item text` and `\Wrong{text}{explanation}`
  with `\item text` — no colors, no explanations, no answer keys in `\QBlock`.
